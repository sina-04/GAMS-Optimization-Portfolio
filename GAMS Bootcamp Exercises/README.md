> **License boundary:** this directory is not covered by the repository's MIT

These models were developed while following *Optimization with GAMS:
Operations Research Bootcamp A-Z*. They are retained as an educational record
and are grouped by formulation family:

- [`04-LP/`](04-LP/) — linear programming;
- [`05-MILP/`](05-MILP/) — mixed-integer linear programming;
- [`06-NLP/`](06-NLP/) — nonlinear programming;
- [`07-MINLP/`](07-MINLP/) — mixed-integer nonlinear programming;
- [`08-Multi-Objective/`](08-Multi-Objective/) — multi-objective modeling.

The repository does not reproduce course videos or written lessons. The model
files and supplied data may remain subject to course or source-material terms,
so no reuse permission is granted here.

Run an individual exercise from its directory with:

```bash
gams ModelName.gms
```

Generated solver outputs are intentionally excluded from version control.
